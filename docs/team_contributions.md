## Final Integration

The final repository combines all team contributions into one reproducible workflow:

```text
Data collection
-> Data preprocessing
-> Feature engineering
-> Baseline modeling
-> LSTM modeling
-> Final demo
-> Documentation
-> Poster and README
```

Each member contributed to a different part of the final seismic-financial prediction pipeline.
