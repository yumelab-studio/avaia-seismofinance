# Results Summary

## Baseline Result

The initial Linear Regression baseline used earthquake magnitude to predict stock return.

Result:

- MSE: approximately 0.00037
- R² Score: approximately -0.0065

This showed that earthquake magnitude alone was not enough to explain stock return movement.

## Improved Models

After feature engineering, the project compares additional models, including:

- Logistic Regression
- Random Forest
- Gradient Boosting
- LSTM

## Current Findings

The current results suggest that richer earthquake and financial features provide a more meaningful modeling approach than magnitude alone.

The final comparison will be updated after the LSTM model and evaluation metrics are completed.

## Limitations

The dataset is relatively small for deep learning, and stock prices are influenced by many factors beyond earthquakes.

## Future Work

Future improvements include adding more insurance stocks, more market indicators, longer event windows, and real-time earthquake API integration.
